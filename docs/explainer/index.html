How the loop was made

Turning seven layers into one block applied twice, by editing weights

The trained model has seven distinct layers with the schedule F S S F S S F (F = full attention, S = sliding window of ±64 tokens). Layers 1–3 and 4–6 share a schedule, so they can become one block run twice. No gradient step was taken: two exact rewrites line the blocks up, then a closed-form fit ties them.

1

Two trained blocks speak different coordinates

Many weight settings compute the exact same function: heads can be reordered, each head's value space rotated, each RoPE frequency pair turned, MLP units permuted and their gate signs flipped. Trained separately, the two blocks land in unrelated settings of these symmetries, so their weights look unrelated even when their jobs are similar.

Before alignment, the cosine similarity between matching weight matrices of the two blocks is about zero. Press the toggle to apply the exact re-gauge; the function is unchanged (KL to the original 4×10⁻¹⁰).

2

Matching attention heads

Each head of layer 1 is scored against each head of layer 4 (and 2↔5, 3↔6): the best orthogonal fit of the value/output maps plus phase-aligned query/key maps. The Hungarian algorithm then picks the one-to-one matching with the highest total similarity. Layers 1 and 4 match in reverse order.

3

Matching 384 MLP units

The same idea for the GeGLU units: a 384 × 384 matching cost between units of the two layers. As trained it looks like noise. After the Hungarian permutation a bright diagonal appears: unit i of one layer has a partner unit i in the other. Roughly half the gate signs flip, which is what an arbitrary sign choice in training predicts.

4

Tying: nine ways to make one block

With both blocks in one gauge, one weight set has to serve both positions. Copying or averaging the weights uses no data and loses the most. RegMean solves a least-squares merge from each layer's input statistics; least-squares sweeps then refit every matrix of the tied block, in order, on the looped model's own activations (600 unlabelled train decisions). Bars: KL from the original's choice distribution on 400 held-out decisions; lower is closer.

5

Where the copy goes wrong, and the fit does not

Relative error of the residual stream against the original, layer by layer. A plain copy of layers 1–3 is exact through loop 1 (they are the original's own layers 1–3) and then drifts to 0.38, because layers 4–6 were never meant to receive those inputs. The fitted block gives up a little accuracy in loop 1 to end at 0.12.

6

It is a real loop: run it more times

The same tied block can be applied any number of times. One pass is far from the original; from two passes on, the distance stays flat, and the change each extra pass makes to the option states shrinks from 0.54 to 0.06. The block settles toward a fixed point instead of blowing up. Use the Loops slider at the top to run the flow above at 1–8 loops.

7

What the simulator labels say

Regret is the simulator value of the best option minus that of the picked option (asinh units; 0.1 ≈ 10% of net worth at the horizon). Intervals resample whole maps. Neither difference is significant. The encoder's unique layer weights drop from 3.90M to 2.23M; the 12.9M embedding table is unchanged. The closed-loop gate (full games) has not been run, so the looped model is not a replacement for the incumbent yet.
